# 📱 App Promoción - Ingeniería en Sistemas Computacionales

## 📖 Descripción de la Aplicación
Aplicación móvil nativa para Android desarrollada como herramienta de difusión para la carrera de Ingeniería en Sistemas Computacionales. Su objetivo principal es brindar información clara, moderna e interactiva a estudiantes de nuevo ingreso o preparatoria sobre la malla curricular, las áreas de especialidad y el amplio campo laboral de la carrera.

## 🛠️ Arquitectura y Tecnologías
El proyecto está construido bajo los estándares modernos de desarrollo de Google:
* **Lenguaje:** Kotlin
* **Interfaz Gráfica:** Jetpack Compose (UI Declarativa)
* **Navegación:** Navigation Compose
* **Dependencias de Terceros:** 
  * *Lottie* para animaciones vectoriales.
  * *Coil* para la carga eficiente y asíncrona de imágenes.
  * *Retrofit* para el consumo de servicios web.
